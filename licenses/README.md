# Awesonix Mail 0.115.2 licences

This directory accompanies the Awesonix Mail distribution and preserves the product agreement, concise third-party notice, complete component-level compliance bundle, and source-availability instructions for this release.

The Awesonix agreement applies only to Awesonix-owned portions. Third-party components remain governed by their own licences, and those rights are not restricted by the Awesonix agreement.

The `third-party/` directory contains four exact manifests covering linked Go modules, production web packages, bundled fonts, and runtime data. Every manifest references its preserved licence and notice files by SHA-256. MPL-covered source archives are included directly rather than relying only on external links.
